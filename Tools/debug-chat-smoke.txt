# A scripted debug chat session that touches most chat features. Run a build with:
#   ChaosLeague.exe -debugchat -datadir <empty test folder> -debugchatscript <this file>
# -datadir keeps the test players out of your real database. Lines starting with / are test
# commands (see /help in debug chat); anything else is chat from you, the streamer.

hello from the streamer
/as alice hi everyone
/as bob hello
/wait 1

# Invites: a claim, a second claim (refused), inviting yourself (refused), and the "@name" first message
/as carol !invitedby @alice

/as dave !invitedby @dave
/as erin @alice
/wait 1
